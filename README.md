# ServiceNow Employee IT Onboarding

A hands-on ServiceNow portfolio project built in a Personal Developer Instance.

The solution automates the IT onboarding process for new employees, including equipment requests, approvals, access provisioning, fulfillment tasks and notifications.

## Business Problem

New employee onboarding often requires coordination between multiple IT teams.

The goal of this project was to create a single ServiceNow request that automatically coordinates hardware preparation, user account creation, VPN access and business application access.

## Solution Overview

Manager submits New Employee IT Setup request
→ conditional form logic
→ premium laptop approval
→ automated catalog tasks
→ IT fulfillment
→ request completion
→ email notification
